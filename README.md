
# Premium Chat

A video-first creator-to-fan platform.

## Technology

- React and Vite
- Tailwind CSS
- Zustand
- Node.js and Express
- MongoDB and Mongoose
- Cloudflare R2 for private media storage
- Safaricom Daraja for M-Pesa payments

## Project structure

- `client/` — React application
- `server/` — Express API

## Development

Start the backend:

```bash
cd server
npm run dev
```

Start the frontend in another terminal:

```bash
cd client
npm run dev
```

Frontend: http://localhost:5173

Backend: http://localhost:5000

API health: http://localhost:5000/api/health
